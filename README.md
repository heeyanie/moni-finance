# moni-finance
A Java Swing personal finance management application designed for students.

A student-friendly personal finance management application
built using Java Swing.

## Features

- 💰 Wallet management
- 🐷 Savings tracker
- 💸 Expense tracking
- 📊 Budget monitoring
- 📜 Transaction history
- 🎯 Savings goals

## Technologies

- Java
- Java Swing
- Object-Oriented Programming
